斜俯视 3D 海战动作小游戏

开始游戏 技术说明

限时 Boss 战 · 轻布防成长 · 浏览器即开即玩

游戏类型

一款面向网页端的单人 3D 动作小游戏：斜俯视场景、十分钟一局，在近海海域推进到终局 Boss。

3D 动作海战

斜俯视低多边形场景，以开船撞击为核心操作，强调移动与碰撞节奏。

轻布防 / 成长

融合灯塔、巡逻船等放置单位，以及商店模块强化，形成短局资源循环。

限时 Boss Rush

十分钟倒计时推动节奏；终局目标是击沉大海盗，适合碎片时间开一局。

使用技术

纯前端实现，核心渲染基于 Three.js；无需安装，浏览器直接运行。

  • Three.js
    WebGL 3D 渲染 使用 Three.js 搭建斜俯视场景、网格与相机；角色、船只与敌人均为程序化低多边形模型。
  • Shader
    自定义着色材质 基于 ShaderMaterial 处理 stylized 光照与配色，贴合木牌 UI 的卡通海战视觉。
  • Web
    纯前端可玩原型 HTML / CSS / JavaScript 单页结构，CDN 加载 Three.js；支持键盘与触控，可添加到主屏幕。

在线体验

打开即可游玩。若浏览器工具栏挡住画面，可使用游戏内「全屏」。
